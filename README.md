# 虚构价格工作台演示

仅原创虚构业务数据和有限规则模拟，不包含真实价格/客户、真实AI或正式报价权威。汇率使用有日期来源的公开参考快照，应用不联网取率，不称实时。

```sh
PYTHONPATH=src python3 -m txsenser_pricing.s1_demo --db .s1-demo/experience-v2.sqlite3 --port 8766
```

打开 http://127.0.0.1:8766/?matter=demo-workbench-v1 。默认紧凑矩阵；点调整价格，再点具体价格选中并输入，预览后确认。选中有样式反馈；产品名点击定位该行，单个价格点击只看该项来源。价格类型筛选实际收窄列，清除恢复完整列。金额显示整数，显示舍入不改原参考值；缺价不编造。顶部直接显示已核验近期参考汇率和日期来源，三币任意输入立即换算，无需填率。超过7天或来源数据失效则停止换算并提示，不伪造当前率。不要把新版覆盖到旧9539533目录或数据库；旧方案继续由原入口查看。

在询价区选择虚构客户/项目/产品/数量和条件；缺项待补，有适用参考才可准备演示报价。预览和取消不入报价史，明确确认才记为“虚构已报价”。重新载入可查回，再次询价主动引用历史和条件差异。更正追加版本，旧版保留；报价不等于接受/合同/成交，历史不升级正式价格。

SQLite仅在本机，GitHub代码和检查不是在线后台。默认Host/Origin限制保持；不要直接暴露公网。共享业务权威和真实业务功能不在本演示范围内。

新增检查分别覆盖实际Store/无监听HTTP处理器、使用响应模拟的页面逻辑；浏览器三场景流程只在现有获准标准云端检查运行，不把源码发布当业务验收。
